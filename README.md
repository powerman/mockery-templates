Templates for [mockery](https://github.com/vektra/mockery) v3,
which use it as a generic interface-driven Go code generator:
mockery loads packages, types and imports,
and a template defines only the shape of generated code.
Why this approach is used instead of dedicated generators is explained in
[RATIONALE.md](RATIONALE.md).

## Templates

- [go-mockgen](https://pkg.go.dev/github.com/powerman/mockery-templates/go-mockgen) —
  stateful fakes with the same API as
  [go-mockgen](https://github.com/derision-test/go-mockgen) v2.1.1.
  Frozen: fixes only.
- `fake` — stateful fakes with an own evolving API derived from go-mockgen (planned).

The generated API, naming rules and `.mockery.yml` examples of a template
are documented on its pkg.go.dev page.

## Installation

Copy the template with its JSON schema into the project, e.g. into `.mockery/`,
and refer to it in `.mockery.yml` as `template: file://.mockery/go-mockgen.templ`:

```sh
mkdir -p .mockery
for f in go-mockgen.templ go-mockgen.templ.schema.json; do
    curl -fsSLo ".mockery/$f" \
        "https://raw.githubusercontent.com/powerman/mockery-templates/refs/tags/v0.1.0/go-mockgen/$f"
done
```

A copy works offline and shows template updates as ordinary diffs.
Alternatively, refer to the template by URL and mockery will download it
(and the schema next to it) on every run:

```yaml
template: https://raw.githubusercontent.com/powerman/mockery-templates/refs/tags/v0.1.0/go-mockgen/go-mockgen.templ
```

### Delete outputs before running mockery

mockery aborts when any loaded package fails to type-check
([vektra/mockery#721](https://github.com/vektra/mockery/issues/721)),
so an output placed in the interface's own package breaks regeneration
as soon as the interface changes.
Delete all mockery outputs before running mockery
(generated files start with `// Code generated by mockery; DO NOT EDIT.`):

```sh
git grep --untracked -lz '^// Code generated by mockery; DO NOT EDIT\.$' -- '*.go' | xargs -0 -r rm --
mockery
```

This also removes outputs orphaned by changes in `.mockery.yml`.
